Hosted answers a function that does not exist with 404 and `allow-origin: *`, so check the status too. Deploy to hosted before pushing a branch whose CI checks hosted, or the push-event run goes red on timing.
- **Pushing hosted from a worktree (2026-09-28):** a worktree is not linked. Copy `project-ref`, `linked-project.json` and `pooler-url` from the main checkout's `supabase/.temp/` into the worktree's (gitignored), then `supabase migration list --linked` (read-only) before `supabase db push --dry-run` and `--yes`. The password comes from the link cache; no `.env.local` exists or is needed. Deploy functions one per command (`supabase functions deploy push --no-verify-jwt --project-ref amnaxvznkadkgzdxzegw`); a zsh loop over "name --flag" strings passes them as one bad slug. `hosted-smoke.sh` from the Mac can show `000` (no reply in time) for a function on a slow night; a direct curl right after answering 401 settles it, and CI's run is the independent check.
