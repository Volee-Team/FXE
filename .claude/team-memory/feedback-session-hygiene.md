- **Compact, never `/clear`.** Alex, 2026-08-13: *"im never doing clear again this sucks"*; 2026-08-15: *"maybe compact next time instead?"* A `/clear` cost a day of context. Never suggest it.
- **He will not run slash commands.** 2026-08-15: *"im a little traumatized by slash commands ... i just forget to use them + i trust you more to do things instead of me."* Run `/probes` and the like myself; never ask him to.
- **No em-dashes in chat replies**, not only in app copy (stated on Volee, 2026-06-19; the same person). Use a colon, a comma, or a new sentence.
- **Do the task, not the plan** (Volee, 2026-07-16): no phase enumerations, no menus of scope options; build, then report.
- **Paths must be clickable.** 2026-08-15: a relative path in a reply errors when he clicks it. In the desktop app, markdown links relative to the working directory work; plain text paths should be absolute.
- **Delegation to a cheaper model** (2026-09-10, from a Reddit thread he liked): fine for fenced work with a spec and a test (a migration plus its probe, a Playwright test, a web panel); never for simulator or browser verification, copy judgement, or anything touching Tara's rules. He said credits are not the constraint.
- **Wait loops poll a process, never a log line** (2026-09-10: one of mine spun seven hours waiting for a word that never appeared).

**Why:** each was stated once and would otherwise be re-learned. **How to apply:** default session behaviour; none of these need re-asking. Related: [[feedback-how-alex-works]], [[feedback-take-more-control]].
